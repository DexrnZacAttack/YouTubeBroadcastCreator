# YouTubeBroadcastCreator
Used for automatically creating a ready-to-stream YouTube broadcast, printing the stream key for easy automation.

Ideal usage is for streams that you need to be totally automatic, without creating a scheduled stream ahead of time in YouTube Studio.

A good example would be running a 24/7 live stream, if you ever wanted to restart or save the VOD, you would have to manually create another stream through YouTube Studio to get it back up and running.

You can pipe the output into say the OBS Advanced Scene Switcher plugin and automatically set the stream key before starting your stream.
